## New features and improvements

- Qwen3.8-Flash-Next prompt prefill streams each routed expert's weights from memory fewer times, with every output bit unchanged (hash-equal to the previous kernels on layers of the real shape, and equal to the decode path). The routed-expert gate/up and down GEMMs of a layer used to run as three launches by tile count (1, 2 and 3-4 tiles of 16 rows per work item), so an expert with a full item and a remainder item had its weights read from DRAM twice. They now run every work item in one launch, ordered so an expert's items follow each other and the column blocks that run together stream its weights once; each item picks its tile-count instance at run time. Measured on one GB10 with a 4,096-row layer of the Flash-Next shape (512 experts, top-10, skewed routing): gate/up 6.19 to 5.50 ms, down 4.84 to 4.27 ms. On a real cold 32K-token prompt (eight 4,096-row chunks) a steady chunk's gate/up kernels take 298 to 267 ms and its down kernels 202 to 188 ms.
