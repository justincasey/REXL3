## New features and improvements

- Qwen3.8-Flash-Next prompt prefill writes the hyper-connection streams once a layer instead of twice. The MLP pre-mix used to add the attention block's post-inject to the streams in place (one 335 MB write for an 8,192-row chunk) before its three kernels read them; it now leaves the streams as they are and each of the three kernels (norm and inject, down, up + mix) applies the same fused multiply-add to every value it reads, and the next attention pre-mix applies both blocks' posts in one pass and writes the result. Every value is computed by the same operation on the same operands, so the mixed rows, the inject rows and the streams stay bit for bit equal to the in-place posts at every row count (`REXL3_HCG_LAZY_POST=0` restores the old order). On a steady 8,192-row chunk the norm and inject kernel takes 288.3 ms instead of 349.0 ms, the down kernel 302.5 ms instead of 266.5 and the up + mix kernel 239.8 ms instead of 236.4, so a chunk's GPU busy time falls from 3,974 ms to 3,950 ms.
