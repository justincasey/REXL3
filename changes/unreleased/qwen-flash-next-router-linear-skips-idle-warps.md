## New features and improvements

- Prompt prefill of Qwen3.8-Flash-Next runs its router and gate projections (the many-row weight-stationary kernel) with fewer instructions, with every output bit unchanged (tested equal to the per-row kernel and to the previous many-row kernel at 1 to 4,012 rows, the model's 2,560-wide inputs to 512 and 48 columns, and ragged widths, bf16 and f32 outputs). Warps with no second 8-vector of the input row no longer issue the multiply-adds of zero operands for it (their accumulators never hold -0, so skipping the additions changes nothing), and the reduction across lanes keeps each lane's registers in an order that needs no selects: lane L holds output (register index xor L), so every stage adds the partner's register directly. The router projection of a 4,012-row chunk takes 1.35 ms instead of 1.55 ms and the 48-wide gate projections 0.14 ms instead of 0.16 ms a layer.
