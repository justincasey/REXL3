## New features and improvements

- GLM at TP=2 now splits every routed expert's intermediate width between the two ranks instead of giving each rank whole experts. Each rank holds gate/up output columns and down input rows `[r * 1024, (r + 1) * 1024)` of all 288 experts, so both ranks read the same bytes per token; with whole experts the slower rank read about 5 of a token's 8 experts and the other waited at every MoE exchange. Decode and verify windows and P1 prefill chunks keep the single node's bits: each rank computes exactly one of the down projection's two K splits, the existing all-reduce adds the two partials, and the down epilogue and slot combine run after it. `REXL3_GLM_TP_EXPERTS=range` keeps the whole-expert split for A/B; the two ranks must agree (the bootstrap's flags byte and the Hello's ownership fact).
- Under the P2 prefill contract a width rank runs the P2 expert GEMMs on its half of every expert and swaps one part per row as before. The parts are the width's halves, so P2 at TP=2 no longer equals P2 on one node bit for bit; every P2 invariant (determinism, row and chunk independence, drafted == serial, concurrent == solo) still holds.
- The GLM loader reads a column cut of an EXL3 trellis as one strided item (its rows only, at most three copies per staged piece) and a K-row cut as one contiguous item.
