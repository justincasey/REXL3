## New features and improvements

- On a two-rank GLM-5.3-Flash group the DFlash2 drafter (`--draft`) is now split over both ranks (`REXL3_GLM_DRAFT_SPLIT`, on by default; `0` keeps the whole drafter on rank 0). Each rank loads half of every draft layer's attention heads, half of the MLP's intermediate columns and half of the draft head's columns (the restricted head's strips too); a round swaps the o and down partials twice a layer and merges the two halves' top-16 lists in one packed swap, so both ranks hold the same picks. Rank 0 forwards each round's requests and each prompt's end to rank 1 (new calls `dflash_draft` and `dflash_prompt_end`), and each rank taps, absorbs and snapshots its half of the drafter's context. The split is a fact of the TP Hello (with a digest of the draft pack's config) and a boot round checks that both halves make the same picks; every round's picks are compared again in the call's ack. The target path is untouched: every reply, drafted == serial, concurrent == solo and cached == uncached hold as before (the drafts themselves may differ from the whole drafter's at near ties, since each partial is rounded to bf16 before the sum). Measured on two DGX Sparks with RED-SNOW-5.3-Flash: a draft round takes 4.38 / 4.73 / 5.56 / 9.16 ms at 1 / 2 / 4 / 8 streams (6.02 / 6.35 / 7.13 / 11.00 ms whole); prose decode 36.1 -> 37.7 tok/s, the six-prompt mean 45.7 -> 47.4 tok/s, eight concurrent streams 93.2 -> 98.5 tok/s.
