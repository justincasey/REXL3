## New features and improvements

- Qwen3.8-Flash-Next packs with the hashed n-gram embedding (PLE) no longer wait on the NVMe page faults of the n-gram table. The gather of the packed rows is now an allocation-free loop; chunks of 64 or more rows run on 8 helper threads with `MADV_WILLNEED` queued per block, so a cold 4,096-row prefill chunk reads its up to 65,536 rows in 45 ms instead of 14.8 s, and a cold 7-row verify window in 0.27 ms instead of 23.2 ms (one GB10, 39 GB table evicted from the page cache first). The gathered bytes are identical to before. Tunables: `REXL3_NGRAM_THREADS`, `REXL3_NGRAM_PAR_MIN`, `REXL3_NGRAM_WILLNEED`, `REXL3_NGRAM_AHEAD` (`THREADS=1 WILLNEED=0 AHEAD=0` is the previous behaviour) and an optional row-granular cache, `REXL3_NGRAM_ROW_CACHE_MIB` (off by default).
