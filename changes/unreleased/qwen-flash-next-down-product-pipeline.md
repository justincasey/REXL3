## New features and improvements

- Qwen3.8-Flash-Next prompt prefill feeds the hyper-connection pre-mix's down-product kernel better. The raw stream tiles of three stages ahead now sit in three register sets used round robin (the stage loop is unrolled by three, so no copy between sets waits for the load issued a moment before), the norm weights of the next stage travel in the same asynchronous group as the down weights two stages ahead, so the down weights get two loop iterations to land instead of one, and the four 16-wide MMA units of a stage run in the order 0, 1, 3, 2 so that no accumulator's next MMA directly follows its last. Every accumulator still receives its units in the library's order, so every output bit is unchanged (the mixed rows, the inject rows and the post-injected streams stay equal to the 64-row slab loop at ragged row counts). On a 4,016-row chunk the kernel takes 1.33 ms instead of 1.39 ms with a warm L2 and 1.31 ms instead of 1.48 ms with the L2 filled by other data.
