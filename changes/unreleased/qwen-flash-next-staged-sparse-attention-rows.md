## New features and improvements

- Qwen3.8-Flash-Next prompt prefill reads each key/value row of its sparse attention once per block instead of once per warp, with every output bit unchanged (tested equal to the previous kernel at 71 to 4,096 rows covering dense starts, the sparse threshold, block boundaries and several sequences per batch). The three warps of a block serve the same key/value head and read the same rows; they now copy each group of eight rows into shared memory together (one 512-byte asynchronous copy per row, the next group in flight while the current one is computed) and read them from there, with the same arithmetic as before. The kernel's traffic from the L2 cache falls to a third (L2 throughput 79.5% to 35.5% of peak) and a 4,096-row chunk at 512 selected blocks takes 24.06 ms per layer instead of 24.50 ms; the kernel stays limited by instruction issue (83% of issue slots), so the gain is small, 277.6 ms to 273.7 ms per cold 32K-prompt chunk across the 13.5 sparse layers.
