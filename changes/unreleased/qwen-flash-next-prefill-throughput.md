## New features and improvements

- Qwen3.8-Flash-Next prompt prefill is faster with every output bit unchanged (serial replies, prefill and needle replies, drafted == serial, cached == uncached). The hyper-connection pre-mix runs its split-K products as a few large cublasLt calls with the library's own M = 64 algorithm family and fuses the up products and the mix into a tensor-core kernel; the router, shared gate and GDN `a`/`b` projections use a weight-stationary many-row kernel (now up to k = 3,072; the router at 4,096 rows takes 1.9 ms instead of 3.5 ms); prefill attention serves four query heads a warp; the dense prefill linears run the fused chain GEMM.
