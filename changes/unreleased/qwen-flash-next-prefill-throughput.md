## New features and improvements

- Qwen3.8-Flash-Next prompt prefill is faster with every output bit unchanged (serial replies, prefill and needle replies, drafted == serial, cached == uncached): the hyper-connection pre-mix runs its split-K products as a few large cublasLt calls with the library's own M = 64 algorithm family and fuses the up products, the mix and the previous block's post-inject into tensor-core and norm kernels; the router, shared gate and GDN `a`/`b` projections use a weight-stationary many-row kernel; prefill attention serves four query heads a warp; dense prefill linears run the fused chain GEMM. Measured on one GB10 (cold 8K / 32K prompts): 914 / 904 tok/s before, 1,247 / 1,253 tok/s after.
