## New features and improvements

- Prompt prefill of the gated delta net layers (Qwen3.8-Flash-Next, Qwen3.8-27B and the other models that use the same recurrence kernel) spends less time in the sequential recurrence, with every output bit and every recurrent-state bit unchanged (the outputs, the state of every slot and the conv history are tested equal to the previous kernel at sequence lengths that end inside and on the edge of a staging tile, odd totals, several sequences per launch, and a 4,096-row chunk, for the 48- and the 32-value-head builds). The kernel was limited by shared-memory reads of the key and query chunks, which it re-read for every value row; a thread now carries two value rows through each step with the same arithmetic per row, so one read serves both, and the next tile of keys, queries and gates is loaded into registers while the current tile runs and written to the other shared-memory buffer after it. The recurrence of a 4,096-row chunk takes 1.57 ms per layer instead of 2.35 ms (45 layers: 105.8 ms to 70.7 ms per chunk, from kernel traces of cold 32K prompts).
